# Verified real lab dataset

**Primary source:** Donne et al., *Graded Incremental Test Data (Cycling, Running, Kayaking, Rowing)*, Trinity College Dublin Human Performance Laboratory, Zenodo DOI [10.5281/zenodo.10841412](https://zenodo.org/records/10841412), version 2 (2024). This original research archive (`data_v2.zip`, saved here as `data/raw/graded_tests.zip`) was downloaded from the publisher and passed its published MD5 checksum `f64cb1bf4d66129daed6c1954ea6ca9f`. The source describes its database as a research/educational asset. Cite the authors and source in reuse.

**Collection:** Participants underwent graded exercise tests. Cycling workload in watts was progressively increased; capillary blood lactate concentration (mmol/L) was measured at stages. The source has 285 cycling test files. Our deterministic cleaning script `scripts/prepare_graded_tests.py` retains positive cycling workload, blood lactate 0–25 mmol/L and valid file observations. It produces 2,102 real paired measurements from 279 cycling test files, saved as `data/processed/cycling_lactate.csv`. Six original cycling files were excluded because they did not yield a valid measurement under these filters.

**Columns:** `training_load` = workload in watts at that stage; `performance_score` = measured blood lactate concentration in mmol/L. The generic column names preserve the API's upload contract but are explicitly re-labelled in the dashboard. `athlete_id` is the source *test-file ID*. It is **not verified to identify distinct human participants**; repeat tests may exist. `date` is the lab test date. Do not interpret a workload stage as seven-day accumulated training load, and do not interpret lactate as a score of competitive performance.

**Training:** Fitted polynomial curve of degree 2, `lactate = intercept + a × watts + b × watts²`, via `PolynomialFeatures(2)` and least squares `LinearRegression`. All stages of a given test file go exclusively to train or test (80/20 group split, random seed 42). An independent linear model is used as baseline. Five-fold grouped CV is performed only inside the training split to compare degree 1, 2 and 3; mean validation MAEs are 1.238, 1.076 and 1.070 mmol/L respectively. The cubic advantage is minor, so degree 2 is retained. On 422 held-out stage observations from 56 test files: quadratic MAE **0.955 mmol/L**, R² **0.584**; linear MAE **1.151 mmol/L**, R² **0.535**. The split guards against same-test leakage, but repeat participants cannot be excluded across files. Both predictions describe pooled acute physiological response, not longitudinal training adaptation, race performance, medical thresholds or safe exercise prescription.

**Provenance:** Zenodo release https://zenodo.org/records/10841412 ; rebuilding requires `python scripts/prepare_graded_tests.py` from project root. Original source archive is bundled. SoccerMon was tested for the original load-to-match-rating idea, but that one-variable model performed poorly (held-out R² −0.056); its data is not the default or bundled dataset in this release.
